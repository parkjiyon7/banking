1

사용자 질의 수신

2A

상품 안내 질문 → product_agent

Knowledge Base(product_guide)를 벡터 검색하여 금리·조건·혜택 정보를 RAG 방식으로 답변합니다.

RAG Q&A 방식 financial_products_guide.txt 임베딩: IBM Slate-125m
2B

적금 추천 요청 → deposit_advisor_agent

deposit_advisor_flow를 즉시 실행합니다. ① PDF 업로드 → docext 추출 ② 고객 폼 수집 ③ LLM 추천 생성. suppress_agent_summarization=True로 에이전트 재가공 없이 flow 결과를 직접 출력합니다.

No-Code Workflow Document Extractor deposit_products.pdf
2C

환율 조회 요청 → exchange_rate_agent

get_single_exchange_rate 또는 get_all_exchange_rates tool을 호출합니다. searchdate가 없으면 "today"를 넘겨 KST 최근 영업일을 자동 계산합니다.

OpenAPI 한국수출입은행 환율 API 주말·공휴일 시 직전 영업일 fallback
3
